# CS-inspired arsenal asset provenance

All twelve meshes and their mechanical components are original FPSloppa game
geometry authored with Blender. The procedural source is
`tools/cs16/model_weapons.py`, `weapon_shapes.py` and `refine_profiles.py`; the editable workbench is
`tools/cs16/refined/cs16_arsenal.blend`. No Counter-Strike retail assets are used.
Detachable magazines, the connected M249 belt, feed tray and hinged cover are
part of this original geometry. The separated M249 feed components are also
editable in `tools/cs16/refined/m249_feed.blend`. During physical reloads,
`deathmatch/counterstrike/feed_belt.gd` replaces the static belt with original
instanced cartridge and link geometry using the same mipmapped finish. Loose shotgun shells use original runtime
primitive meshes. The contextual magazine pouch is an original Blender-authored
canvas model with an original woven texture, lining, stitched rim, webbing and
belt loops, dedicated to CC0 1.0. Its editable source is
`tools/cs16/pouch/magazine_pouch.blend`; `tools/cs16/build_pouch.py` reproduces the
geometry and `import_pouch.gd` creates the compact native scene. It has 3,092
triangles and five material surfaces, rendered only for the local contextual pouch.

The shared 1024×512 surface atlas is original FPSloppa artwork, dedicated to
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
`tools/cs16/surface_finish.py` produces its padded steel, polymer, walnut, olive,
machined metal, brass, black and amber regions. `paint_finish.py` adds wear using
Krita MCP; the editable layers are in `tools/cs16/refined/cs16-finish.kra` and the
flattened source is `cs16-finish-painted.png`. The import step generates mipmaps
and shares one texture across all models and the moving M249 belt. This replaces
the earlier AFPS donor finish on the CS arsenal. No downloaded third-party model
or texture was incorporated in this revision.

Reference photographs are not distributed. The knife is an original clip-point
design. All models are stylized game assets, not exact replicas. The existing
project sound library is reused; no original CS audio is included. Wheel icons
are original SVG geometry generated by `tools/generate_weapon_icons.py`.

`sources.json` records authoring and final asset hashes. Authoring sources, reference
downloads and inspection renders are excluded from game exports by the existing
`tools/*` and `test-results/*` filters.

Reload and defusal Foley: six original synthesized mechanical cues, CC0-1.0. Source generator:
`tools/cs16/build_reload_sounds.py`; source WAVs: `tools/cs16/reload_audio/`;
runtime audio: `deathmatch/audio/cs16/`. No sampled third-party recordings.
