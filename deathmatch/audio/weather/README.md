# CQ weather audio

Original procedural rain and distant thunder, generated by
`tools/voxel_battle/generate_weather_audio.py` (fixed seed 290421).
No third-party recordings or samples are used. Mono 22,050 Hz WAV sources;
rain is an eight-second circular-noise loop and thunder is a five-second
filtered noise/low-frequency clap with a decaying envelope. The weather node
explicitly loops rain and plays thunder once after the acoustic delay.
