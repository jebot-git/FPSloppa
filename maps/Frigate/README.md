# Frigate

Independent Frigate-inspired harbor Assault for FPSloppa. Start with 4–8 players
and a six-minute attack. Board via the wooden gangway or submerged starboard
intake, destroy the aft compressor, then activate the bridge gun console.

Dive below the intake lintel; once inside, swim up the wide ramp onto the main
deck. A separate ramp at the eastern end of the quay returns swimmers to shore.
Two internal stair routes reach the mess deck.

Built from original CC0-1.0 brush construction with LibreQuake textures under
the accompanying BSD notices. This is an adaptation, not an official or exact
Unreal Tournament map. No retail Unreal assets are included.

See [construction, references and validation](../../tools/frigate_concept/README.md).
`texture-sources.json` records embedded mipmap hashes and donor provenance.

Updated clients and server are required for the shootable compressor objective.
The local BSP and caches are ready for source-build playtesting; the normal
asset packaging tool includes them in the next base package.
