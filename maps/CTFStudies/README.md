# FPSloppa CTF Studies

Six newly authored CTF adaptations of the original ThreeWave CTF1–CTF6 route concepts.
See [research and build notes](../../tools/threewave_rebuild/README.md).

New geometry: CC0-1.0; original map designs and names are not relicensed.
Material artwork: Makkon (project permission and bundled licence) and LibreQuake (BSD).
`texture-sources.json` pins the source archive, WAD and original miptex hashes.
No original ThreeWave geometry, artwork, audio or model files are build inputs or package contents.

Each map directory contains editable MAP source, authored landmarks/flags/spawns,
a compiled-texture audit, and the BSP hash used for the navigation bake.
