# Vesper independent district map pack

Sixteen local-coordinate BSP29 maps for the opt-in CQ district-map experiment. See [architecture, launch and rebuild instructions](../../docs/CQ-DISTRICT-MAPS.md).

Each `district_00`–`district_15` folder contains editable `district.map`, embedded-texture `district.bsp`, layout/build/validation receipts and prepared collision, navigation and presentation resources. `manifest.json` binds the pack's identities. Keep it synchronized by rebuilding preparation caches and running `tools/cq_maps/manifest.py` after changes.

`city.wad` is the shared rebuild texture input. `texture-sources.json` retains the provenance and licenses of the existing project texture sources. The generator adds one plain compiler utility texture named `skip`. Geometry is newly generated by `tools/cq_maps/build.py`; existing Vesper art and the project's night panorama are reused. Generated compiler logs, portal and texinfo scratch files are not source assets.
