# Vesper campaign atlas

81 independent BSP29 maps for the experimental persistent campaign. See [rules, launch, rebuilding and validation](../../docs/CAMPAIGN-81.md) and the [district plan](../../docs/validation/campaign-81-plan.png).

Each directory contains source geometry, its final textured map/WAD, baked BSP, collision/navigation/presentation caches, metadata and validation receipts. `materials.wad` contains the expanded original Makkon texture selection; its provenance is in `materials.json`. Per-map `texture-sources.json` records all embedded materials. Existing [LibreQuake credits](../../deathmatch/maps/texture_replacements/LibreQuake-CREDITS.txt) and [Makkon permissions](../../tools/makkon/README.md) apply. No new AI-generated raster assets are used.
