# Launcher icon

Final asset: `deathmatch/icon-final.png`, a 1254 × 1254 opaque PNG. Godot uses it as the project/launcher icon and resizes it for exported platforms. It was generated with the built-in image generation tool, not the CLI. The original is also retained under the session's `.codex/generated_images` directory. The design is an original angular metal helmet with a red visor against charcoal, with no text or existing game branding.

Exact generation prompt:

> Use case: logo-brand. Asset type: final square launcher icon for an independent classic arena VR shooter. Primary request: create a polished, original sculpted sci-fi combat helmet emblem with a single horizontal visor, bold angular silhouette and restrained industrial detailing, readable at small app-icon sizes. Style: premium stylized 3D game emblem, crisp edges, strong light and shadow. Composition: one centered helmet, generous safe margin of 20 percent on every side for headset launcher masks, opaque dark charcoal background filling the square edge to edge. Use the game's existing dark charcoal, muted red and pale metal visual identity. No lettering, no words, no border, no rounded-corner mask baked into the image, no watermark, no resemblance to a specific existing game character or logo. Output a square 1024 by 1024 PNG.
