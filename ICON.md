# Launcher icon

The current icon is `deathmatch/icon-final.png`, a 512 × 512 opaque PNG based on
the SloP title artwork. It combines blue/gold lettering with the white-haired
bundled VRM heroine and was checked at 64 × 64. Godot uses it for the project,
Windows executable and Android launcher fallback.

Generated with the built-in image generation tool. The 1254 × 1254 source,
reference provenance and exact prompt are documented in
[docs/art/slop-icon.md](docs/art/slop-icon.md).
