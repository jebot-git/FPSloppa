# Jungle authoring assets

Original artwork authored through Krita 6.0.4 and Krita MCP for Jungle Frontier.
No downloaded tree images or third-party model assets are required.

* `trees.kra`: editable trunks/branches, broadleaf crowns and palm fronds.
* `trees.png`: transparent 1024×1024 atlas. Left half: broadleaf tree;
  right half: palm. Both represent a 14 m wide, 20 m tall tree card.
* `author_trees_krita.py`: reproducible painting recipe for Krita's libkis
  Python context (`doc` is the active 1024×1024 transparent document).
* `map-overview.kra`: generated terrain overview with a separate Krita layer
  for sites, reservations and legend.
* `map-overview.png`: exported map plan; yellow points are the five existing
  sites and cyan points are the six reserved pads.

The terrain image is generated by `tools/voxel_battle/validate_jungle.gd` from
exactly the runtime landscape source. `tools/voxel_battle/jungle_sites.json`
contains site coordinates in metres. Asset use follows the repository licence.
