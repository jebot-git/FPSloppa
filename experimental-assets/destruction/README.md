# Original reactive wall fragments

`wall_shards.tscn` is an original deterministic eight-cell Voronoi slab, generated by `tools/voxel_battle/bake_wall_shards.gd`. It contains shared static meshes and no physics nodes. Runtime applies short transform animations only.

`wall_topology.res` is a compressed original lookup generated by `tools/voxel_battle/bake_destruction_topology.gd` from the existing CQ architecture; it maps wall IDs to near/middle triangle offsets and preserved vertex attributes, and building IDs to collapse masks including authored rooftop/fixture attachments. It also stores compact per-building animation meshes with the existing baked vertex attributes and shared materials. Those meshes and reusable fragment nodes are prepared before impacts. Regenerate when the stored source hashes change. It is not a third-party VoronoiShatter resource.
