# Titanball cockpit, scope and Pyro feedback

Cockpit manual aiming now uses **left joystick for lateral aim and right joystick for elevation**, shared by all four cannons. Each trigger still fires its own linked upper/lower pair with its existing shared heat meter. Either held grip enables manual aiming for both pairs; an unheld axis retains its current angle. Automatic sentry targeting returns when both grips release. Each stick ignores movement on its unused axis. The neutral zone is approximately 1.5 cm and full deflection requires eight centimetres rather than eleven. Deflection controls angular speed: centered held sticks preserve the current aim, with small deflections providing fine adjustments. Pulling the right stick back raises aim; pushing forward lowers it. The monitor labels the axes, displays the actual aim angles and projects two cannon reticles using the same barrel directions as manual firing. Markers remain at the upper/lower screen edge when the aim is outside the display, labeled ABOVE or BELOW. Turret rotation speed, 15-degree lateral coverage, elevation limits, damage and heat statistics are unchanged.

The sniper helper beam is removed for both the TF sniper and UT rifle. The scope's clear picture diameter inside the existing lens is increased by approximately 15% by reducing the vignette, and its usable eye alignment area is slightly wider. The viewport sampler now uses the sRGB source-color hint and 0.85 linear image gain, correcting the overly bright lens image. A neutral patch measures 0.566 displayed luminance versus 0.609 in the source image. Magnification, render resolution and single-camera rendering remain unchanged. Rendered tests pass with either eye, preserve shot-axis alignment and block views through nearby walls.

The Quake experimental combat path now sends the existing bounded flame effect for the Pyro weapon instead of bullet impacts. A dedicated original synthesized flame-jet sound replaces the slot-7 nailgun report, and the generic muzzle-flash light is suppressed for this weapon. Ordinary slot-7 weapons retain their own effects. Damage, cells, range and burning behavior remain authoritative and unchanged. `tools/generate_flamethrower_sound.py` reproduces `deathmatch/audio/flamethrower.res` without third-party recordings. The flame cue is mono, 22,050 Hz and 240 ms, overlapping the normal 120 ms firing cadence.

TB preparation now shows **HANGAR OPENS IN M:SS** in the shared player HUD; the cockpit monitor retains its preparation timer. The final ten seconds use the existing `round_tick.wav` clock sound. Preparation and match countdowns have distinct keys so snapshot corrections do not duplicate ticks and the match countdown remains available later. The sixty-second preparation does not consume the ten-minute match timer.

## Verification and live test

- 29 cockpit input/authority checks pass, including independent axes, shared elevation, trigger/heat limits, fresh-grip acquisition, tracking loss, stale input, dismount rejection, neutral aim retention and incremental correction. A simulated VR pass also verifies both reticles move up/down with actual cannon elevation and the cockpit remains private.
- 22 rendered optic/FX checks pass. Before and after lens images are retained in `test-results/tb-controls-optics/` and `test-results/weapon-variants/`.
- Ten flame feedback checks pass using real authoritative firing, replicated/demo events, actual rendered flame geometry and sound selection. The test uses the built-in spatial player for direct stream assertions because Steam Audio wraps sources in `SteamAudioStream`. Early assertions incorrectly assumed the wrapper exposed the original resource path; these were corrected. The flame test retains resource/object teardown diagnostics despite passing its behavior checks.
- Six preparation-clock tests pass: ten ticks, no duplicate tick after correction, independent match countdown, unchanged match time, player HUD text and silence during intermission.

An empty offline VR test was launched on `tb_ashfall`: one player, red attackers, no bots, using the current working tree. Telemetry confirms the headset is focused and the match contains exactly one player. The live engine log records each preparation tick from ten through one. Logs are in `test-results/offline-tb-vr-20260914/`. The wearer confirmed split controls, preparation ticks and flame visuals. They then requested inverted vertical control, a larger neutral zone, moving reticles and a dimmer scope; those changes passed automated/rendered checks and were launched in a refreshed empty VR session under `test-results/offline-tb-vr-20260914/reticle-pass/`. Feedback on this final revision remains pending. These changes are unpublished.
