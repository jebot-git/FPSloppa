# Optional LibreQuake Expansion

Thirteen original LibreQuake multiplayer arenas, lqdm1–lqdm13, are optional and are **not installed with the base game**. This combines the former eight bundled arenas and five Extra Maps. FPSloppa's named Makkon/LibreQuake material treatment is retained. It does not include the four KOTH or four CC derivatives; those are in the base game under separate IDs.

Extract `FPSloppa-<version>-LibreQuake-Expansion.zip` into the external asset directory containing `maps/` and `vrm/`, then restart the map menu. The optional maps will be discovered. Keep `maps/LibreQuakeExpansion/` with copies so the original credits and licences remain available. The archive never overwrites standard mode maplists or server.cfg. Examples in this directory show how to explicitly select the original eight arenas in a personalised server maplist.

**Tested modes:** the formerly bundled lqdm1–lqdm8 were each exercised in DM, IG, FT and TDM using eight production bots for 45 simulated seconds per map/mode combination (32 compatibility runs). Earlier extended bot tests also covered these mode families, including a five-minute TDM match and Freeze Tag matches. The original Hyperborea and Basement additionally have CC gameplay evidence. This establishes compatibility, not competitive balance or 16-player VR performance. The extra lqdm9–lqdm13 retain their existing geometry/spawn validation; the new four-mode matrix does not claim coverage for those five extra maps.

Original maps and assets: **LibreQuake contributors**, BSD-3-Clause; see COPYING/CREDITS and the supplied upstream documentation. Makkon material artwork has its own included licence. No commercial Quake installation or original id Software texture WAD is required.

Base DM, IG, FT and TDM now use seven Quake source ports; base CC uses four purpose-built LibreQuake derivatives. Installing this expansion does not change those default rotations. Imported maps and personalised server lists remain supported.

Existing installations retain previously installed maps and personalised maplists. The new base selection applies to fresh distributions; the updater does not delete an operator’s optional/imported arenas.
