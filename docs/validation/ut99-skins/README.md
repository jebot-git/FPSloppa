# Current UT99 base models, UTX import and recognition validation

Godot 4.7.2 on Arc A770, Mobile Vulkan for rendered checks. These receipts cover the constrained production head/neck/arm solver and UTX import flow. Earlier [32/64 shooting benchmarks](../ut99-avatars/README.md) preceded these changes and do not measure their frame cost.

- [Runtime](runtime.log): 114 checks pass across the 12 built-in selections, native animations, geometry, cache and removed tracking channels.
- [Constrained IK](ik-all-models.log): all five stock meshes, 62,316 extreme arm targets across every animation-frame socket. Fixed arm lengths, elbow limits, finite transforms and attachment points pass; head/neck constraints and complete region coverage pass.
- [UTX reader](utx-reader.log): five stock packages and World Leaders parse. All 357 stock textures match prior converter RGB exports exactly for P8; DXT decoder interpolation is allowed one channel unit. Malformed/truncated/count-bound cases reject.
- [Import and recognition](utx-import.log): all five packages select their expected base model; renamed Commando and Female Commando packages match by layout. Ambiguous layouts report uncertainty and retain a compatible selection. Incompatible filenames cannot bypass slot checks. Manual overrides remain available. All imported models validate and render; original frame bytes, clips and IK data survive skin replacement. Different faces have distinct hashes and repeat imports are deterministic.
- [Rendered picker](picker-render.log): real picker automatically suggests Soldier for World Leaders, changes to SGirl by manual override, then imports Putin on Soldier. [Recognition screen](picker-recognition.png), [imported skin preview](picker-imported.png). Capture test does not press USE THIS MODEL or change the user's advertised selection.
- [Three-peer network scenario](utx-network.log), [summary](network-summary.json): uploader → validating server → initially uncached receiver. The receiver's base model, source-skin identity and PNG atlas match the imported fixture exactly, and the downloaded avatar animates. Restart discovery, late rejoin and avoidance of repeat cached transfers pass. Payload 6,211,758 bytes; test alters the fixture title to force a distinct identity.
