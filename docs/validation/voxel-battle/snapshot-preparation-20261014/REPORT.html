The branch now defaults to authority sampling plus one frozen snapshot submission, with native CQ class/reload projection and independent-record expansion on the encoder thread. Wire bytes, record ordering, update cadence, packet budgets, generation/epoch guards and two-job queue bounds are preserved. Public snapshots remain complete for recording, listen servers and gateways. The live service remains on release 6abfbf5; these were isolated candidate tests on UDP 7779.

Correctness and reuse

The selected portable native library passes 1,382 snapshot differential checks, including exact state/record/packet bytes, mutation after submission, ACK life changes, magazine fields, ordnance, movers, malformed input, owner-thread guards and queue bounds. All 18 packaged regression stages pass, including the dedicated server/client test and full class-state demo capture. The existing eight-resource arena teardown diagnostic is recorded and allowed; unrelated engine errors fail the suite. Legacy CQ/jetpack demo playback validation is not claimed by the capture test.

The generic queue/layout APIs are reusable in main. CQ source capture requires the same class/reload schema. docs/NATIVE-CQ-BACKEND.md documents ownership, reference switches and tests. The full C++ scene reader is experimental: it is slower locally than thin GDScript sampling. Scene access remains on the authority; workers read owned frozen values. The bounded queue checks capacity before copying, and reset/shutdown join the encoder and discard prior-generation work.

Large raw traces, process samples and full logs remain in the local/VPS validation directories. This folder retains compact profiles, fleet results, build/source hashes, regression evidence and the rejected experiment patch. The working tree is uncommitted and its base commit and source hashes are recorded explicitly.
